Solana Launchpad Ecosystem - AI Edition

This repository demonstrates a hybrid blockchain architecture: deterministic on-chain programs handle asset management and liquidity, while off-chain bots use the OpenRouter API to make intelligent economic decisions.

The off-chain bots are written in Python, and the on-chain Anchor programs are documented as architectural design-reference specifications under .claude/skills/. For the original system architecture, see manifest.json.

System Overview

  • ICO Factory: A standard bonding curve launchpad design.
  • Affiliate System: An on-chain program design whose commission rates are dynamically set by an AI bot.
  • Barter DEX: An oracle-based DEX design that uses AI-generated prices for swaps, instead of a traditional static AMM formula.

Repository Structure and Component Documentation

  • manifest.json: Primary source of truth for the system architecture.
  • bots/optimizer_bot.py: Off-chain bot to set affiliate commissions via AI.
  • bots/price_keeper_bot.py: Off-chain bot that acts as a price oracle for the DEX.
  • bots/shared/genesis_common.py: Shared constants/PDA/math utilities in Python.
  • .claude/skills/: Architectural design-reference skill specifications.
  • programs/factory-program: ICO launchpad specification. (See Specification)
  • programs/affiliate-program: Affiliate data management specification. (See Specification)
  • programs/barter-dex-program: AI-powered oracle DEX specification. (See Specification)

Setup and Execution

The off-chain bots can be run directly:

  1. Prerequisites: Python 3.10+, pip install -r bots/requirements.txt.
  2. API Key: Create a file at ~/.api-openrouter with your OpenRouter API key (or set OPENROUTER_API_KEY).
  3. Wallet: A Solana CLI keypair at ~/.config/solana/id.json.
  4. Run: python bots/optimizer_bot.py or python bots/price_keeper_bot.py.
