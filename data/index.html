What counts as an interaction

Each chat reply, spoken voice line, picture request and API call WaifuAI Cloud handles counts as one interaction. Bars split every complete week into chat, AI operations (internal calls + decisions), image (images + background images) and voice (transcription + text-to-speech) using the same per-call records that drive the local Analyze Charts view; the gray remainder is traffic those records do not classify — plain API calls, automated traffic, and voice lines before recording began on 24 October 2026. Weekly bars cover complete Monday–Sunday weeks (Asia/Singapore, like the rest of this page); the striped bar estimates the current week from its recorded daily average. Hover or focus a bar for the full seven-category breakdown. Data through 8 November 2026.

Before doing heavier work — drawing a picture, changing a scene, picking an emotion or a voice — the companions ask a small decision model what to do. Confident “nothing to do” answers let the app skip the heavier call entirely: 7,781 of 47,425 answers so far (16%).
