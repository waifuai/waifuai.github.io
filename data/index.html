What counts as an interaction

Each chat reply, spoken voice line, picture request and API call WaifuAI Cloud handles counts as one interaction. Bars split every complete week into the same call types the local Analyze Charts app uses — chat, internal calls (titles, summaries and other behind-the-scenes model calls), decisions, images, background images, transcription and text-to-speech; the gray remainder is traffic those per-call records do not classify — plain API calls, automated traffic, and voice lines before recording began on 24 October 2026. Weekly bars cover complete Monday–Sunday weeks (Asia/Singapore, like the rest of this page); the striped bar estimates the current week from its recorded daily average. Hover or focus a bar for the per-category numbers. Data through 18 November 2026.
