llms-full.txt and llms-full.html

Tools that bundle a project's docs and code into one file a language model can read.

llms-full.txt generatorllms-full.html generator

llms-full is a proposed companion to robots.txt and sitemap.xml: one file with a site's full documentation and code, so an LLM can take it all in at once. This site publishes its own short index at /llms.txt.

llms-full.txt generator

Bundles a directory of docs and code into a single Markdown file.

  • Generates llms-full.txt from any directory.
  • Extra scripts build a Markdown table of contents and count lines and characters of code.
  • File extensions and exclude patterns are set in config.yaml.

github.com/waifuai/llms-full-txt

llms-full.html generator

The same idea as HTML, with a summary for every file.

  • Generates llms-full.html from any directory.
  • Uses an OpenRouter model to write a short summary of each file, so a model can skim before reading.
