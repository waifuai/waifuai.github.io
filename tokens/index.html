About the data

Source. Aggregate AI coding-tool telemetry collected locally by Token Monitor and synced into a snapshot this page is rendered from. Day keys follow the collector's local wall clock (Asia/Singapore). Data through 2026-11-10.

Costs are estimates. USD figures price each model at its API rate — they are what the same usage would have cost on the API, not vendor bills or subscription spend. Snapshot synced 2026-11-12T17:03:42Z.

Free tiers carry no price. 549,876,510 tokens recorded on free or subsidized usage contribute $0 to the estimates, so the cost total is a floor, not a ceiling.

tokens = 0 is not free usage. 33 observations record usage the source tool logged without token counts; they appear in the message counts, not the token totals.

Derived estimates. None recorded yet. Should a client that reports no measured token counts (such as Qoder's global edition) start contributing, its tokens are derived from transcripts, priced at API rates and flagged ≈ here and in every table.

What is not here. Day-level aggregates only — no sessions, prompts, projects, file paths, device identifiers or sub-day timestamps leave the machine.
