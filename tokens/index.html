About the data

💾Collected locally

Aggregate AI coding-tool telemetry collected locally by Token Monitor and synced into a snapshot this page is rendered from. Day keys follow the collector's local wall clock (Asia/Singapore).

🧾Estimates, not bills

USD figures price each model at its API rate — they are what the same usage would have cost on the API, not vendor bills or subscription spend. Snapshot synced 2026-11-24T11:48:43Z.

🎁Free tiers are priced at paid rates

1,255,101,238 tokens arrived as free-tier variants; they are canonicalized into their base model (router prefixes, free suffixes, dated snapshots, region tags and reasoning-effort variants stripped) and priced at its paid API rates across the raw token buckets — an API-equivalent estimate rather than $0.

🧮Cost total is a floor

556,700,188 tokens have no API rate on record — subscription-included routes, models without a published price, or individual buckets (such as cache writes) a model prices only in part — and contribute $0 to the estimates, so the cost total is a floor, not a ceiling.

∅tokens = 0 is not free usage

37 observations record usage the source tool logged without token counts; they appear in the message counts, not the token totals.

ℹDerived estimates are disclosed

1,249,056,090 tokens (8.3% of the total, from Qoder) are derived approximations: derived from transcripts and priced at API rates (no measured token counts). They stay in the totals and are disclosed here rather than marked per row.

🔒Nothing personal

Day-level aggregates only — no sessions, prompts, projects, file paths, device identifiers or sub-day timestamps leave the machine.
