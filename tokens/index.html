About the data

Source. Aggregate AI coding-tool telemetry collected locally by Token Monitor and synced into a snapshot this page is rendered from. Day keys follow the collector's local wall clock (Asia/Singapore). Data through 2026-11-12.

Costs are estimates. USD figures price each model at its API rate — they are what the same usage would have cost on the API, not vendor bills or subscription spend. Snapshot synced 2026-11-12T21:18:42Z.

Free tiers are priced at paid rates. 883,380,648 tokens arrived as free-tier variants; they are canonicalized into their base model (router prefixes, free suffixes, dated snapshots, region tags and reasoning-effort variants stripped) and priced at its paid API rates across the raw token buckets — an API-equivalent estimate rather than $0.

Unpriced usage stays $0. 580,407,231 tokens have no API rate on record — subscription-included routes, models without a published price, or individual buckets (such as cache writes) a model prices only in part — and contribute $0 to the estimates, so the cost total is a floor, not a ceiling.

tokens = 0 is not free usage. 33 observations record usage the source tool logged without token counts; they appear in the message counts, not the token totals.

Derived estimates are flagged. 354,386,440 tokens (3.0% of the total, from qodercn) are derived approximations: derived from transcripts and priced at API rates (no measured token counts). They are marked ≈ wherever they appear.

What is not here. Day-level aggregates only — no sessions, prompts, projects, file paths, device identifiers or sub-day timestamps leave the machine.
