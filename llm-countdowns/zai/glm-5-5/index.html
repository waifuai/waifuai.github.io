Why this date

  • Z.ai released GLM-5.4 on Nov 23, 2026: Z.ai lead Zixuan Li announced it is available to all GLM Coding Plan users, with new vision capabilities, stronger all-round coding performance and 50% more weekly quota than GLM-5.3; the model id is glm-5.4 (glm-5.4[1m] for the 1M-context setting in Claude Code). The announcement carried no benchmarks
  • The docs.z.ai release notes and model guide still list GLM-5.3 (Aug 18) as the newest at the Nov 23 check (changelog lag), and the AA Data API free catalog fetched Nov 23 (index v5, 765 rows) has no GLM-5.4 row yet, so the measured anchor stays GLM-5.3 (31.7) until 5.4 is scored
  • GLM-5.5 is a speculative successor label, not an announced model; an unconfirmed community rumor says it could arrive next month at around 3T total parameters — that rumor is not used for the date
  • Repeating the 97-day interval from GLM-5.3 (Aug 18) to GLM-5.4 (Nov 23) gives Feb 28, 2027; one interval is a weak forecasting basis, not an announced schedule. The 09:00 UTC / 17:00 SGT target aligns the displayed date, not a verified launch hour.
  • GLM-5.3 reads 31.7 on the v5 index. GLM-5.4 has no v5 score yet and GLM-5.2/5.1/5 have none in the Nov 23 AA API catalog, so no same-index v5 delta exists. The +4.2 keeps the owner-approved labeled scenario scaled from the old-index post-training refresh GLM-5.2->5.3 (+7, 53->60 on v4.1.1, +13.2%) onto the retained 31.7 anchor, projecting about 35.9 (scaled from v4.1.1 - scenario, not a v5 benchmark). Third-party reports describe GLM-5.4 as a Loop Transformer architecture step; the old-index architecture scenario (GLM-5.2 +11 over GLM-5.1, 40->51 on v4.1, +27.5%, about +8.7 scaled) is not applied because that architecture claim is unverified and concerns 5.4, not 5.5.
